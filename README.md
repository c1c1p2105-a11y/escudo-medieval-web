# Hierro & Roble — Escudo medieval 3D

Proyecto de modelado y texturizado PBR para web, con Google model-viewer.

## Ver el proyecto

https://c1c1p2105-a11y.github.io/escudo-medieval-web/

## Interacciones

- Cambiar el acero entre acabado natural y pavonado.
- Cambiar la madera entre roble y nogal.
- Activar o desactivar el normal map del bronce.
- Restablecer materiales, girar, acercar y ver frente/reverso.

## Modelo

- 23,679 triángulos; cuatro mallas y cuatro materiales: madera, acero, bronce y cuero.
- Texturas de 1024 px y 512 px; mapas Base Color, Roughness, Metallic y Normal.
- GLB de 7.47 MiB, UVs en todas las piezas.
- Texturas procedurales originales; reconstrucción aproximada de una referencia frontal y reverso interpretado.
- Validación glTF: cero errores y cero advertencias.
